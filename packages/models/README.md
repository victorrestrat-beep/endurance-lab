# @endurance-lab/models

Dependency-free TypeScript models for endurance training: power–duration curve, critical power and
W′, 3-minute all-out test, W′ balance, durability, interval detection, training load and intensity
domains.

Every function is pure and takes power sampled at 1 Hz, in watts. Generators of synthetic rides for
tests and demos are exported from `@endurance-lab/models/synthetic`.

See the [repository README](../../README.md) for usage, and [docs/science.md](../../docs/science.md)
for the equations and references.
